# Windows Notes

### An extremely simple note taking application designed for quick note taking. No bloat, just simple notes with no hassle.

## Installation and usage
1. Run the executable.
2. Press CTRL + Shift + Space to spawn a new note Window.
3. To kill the app, go to the icon tray on the right bottom corner of Windows, right click on the app and click "close" or press Win + R and type `taskkill /f /im WinNotes.exe`
